# План code-review: модуль src/discount.py

## 1. Цели ревью
- **Точность расчётов**: итоговая цена корзины должна рассчитываться без ошибок округления и потери копеек.
- **Защита от фрода**: исключить возможность получить скидку больше максимально допустимой или отрицательную цену.
- **Корректность применения скидок**: базовая скидка, промокоды и уровень лояльности должны применяться в правильном порядке и предсказуемо.
- **Читаемость и поддерживаемость**: код должен быть понятен новому разработчику, без «магических чисел».

## 2. Измеримые критерии (Definition of Done для ревью)
- [ ] **Отсутствие магических чисел**: все коэффициенты и пороги (15000, 0.85, 500, 0.90, 0.97, 0.93, 0.70) вынесены в именованные константы.
- [ ] **Валидация входных данных**: проверяется `cart_sum >= 0`, `tier ∈ {0, 1, 2}`, `promos` — список строк (или `None`).
- [ ] **Покрытие тестами > 80%** (проверяется через `pytest --cov`), включая граничные случаи (пустая корзина, несколько промокодов, максимальная скидка).
- [ ] **Линтер проходит**: `flake8` без ошибок, длина строк ≤ 80 символов.
- [ ] **Порядок промокодов не влияет на результат** (идемпотентность) — либо это поведение явно задокументировано в docstring.
- [ ] **Есть docstring** с описанием параметров и возвращаемого значения.
